# Goal Focus - Architecture Overview

This document outlines the high-level architecture for Goal Focus platform.

- Backend: Node.js + Express + MongoDB (Mongoose)
- Frontend: React + Vite + Tailwind CSS
- Realtime: Socket.IO
- Media: Cloudinary
- Payments: Razorpay / Stripe
- Caching: Redis

Repository layout and next steps are in README files per workspace.
